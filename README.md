# ESP32 Setup

1. Download and install the latest version of the Arduino IDE from the official website: https://www.arduino.cc/en/Main/Software
2. Download and install the ESP32 drivers from the official website: https://www.silabs.com/developer-tools/usb-to-uart-bridge-vcp-drivers?tab=downloads
3. Open the Arduino IDE and go to Settings (`cmd + ,`) in `Additional Board Manager URLs` add the following link: `https://dl.espressif.com/dl/package_esp32_index.json`
4. Select `NodeMCU-32S` as the board and the correct port in the Arduino IDE
